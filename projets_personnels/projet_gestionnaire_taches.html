Gestionnaire de tâches en C# (Windows Forms, JSON)

Informations Clés

Cadre de Réalisation :

  • Type : Projet de développement personnel
  • Durée : 1 semaine
  • Rôle : Projet solo

Technologies & Outils :

  • C#
  • .NET (Windows Forms)
  • Visual Studio
  • JSON (pour la persistance)

Compétences & Qualités :

  • Développement d'interface graphique (C#)
  • Programmation orientée objet
  • Manipulation de données JSON
  • Gestion des événements utilisateur
  • Conception d'application de bureau
  • Autonomie, Organisation

Voir sur GitHub

Présentation Générale

L'objectif était de développer une application de bureau en C# avec Visual Studio pour la gestion de tâches quotidiennes. L'application devait offrir une interface graphique interactive et assurer la persistance des données entre les sessions grâce au stockage en JSON.

Points clés

L'application permet une gestion intuitive des tâches grâce à son interface Windows Forms. Les fonctionnalités principales incluent :

  • Ajout, suppression, et modification de l'état des tâches (cocher/décocher).
  • Tri des tâches par ordre alphabétique (normal ou inversé).
  • Sauvegarde et chargement automatique des tâches via un fichier JSON, garantissant la persistance.

Le développement a été mené en une semaine, aboutissant à une application fonctionnelle et facile d'utilisation.

Apprentissages & Perspectives

Ce projet a permis de consolider mes compétences en développement C# et en conception d'interfaces graphiques simples. L'application est pleinement opérationnelle pour un usage basique.

  • Points forts : Gestion fluide des tâches, persistance des données fiable.
  • Perspectives d'amélioration : Ajout de fonctionnalités avancées comme la gestion des priorités, des notifications, ou la synchronisation multi-appareils.
